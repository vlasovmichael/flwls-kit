# Отступы

Сетка 4 px. Внутри компонента — малые шаги, между карточками и разделами — большие. Отступ, которого нет в
шкале, в стилях не пишется.

<ds-tokens kind="space"></ds-tokens>

## Правила

- Расстояние внутри группы меньше, чем между группами: так глаз сам видит, что с чем связано.
- `--gap` — единственный адаптивный отступ: между разделами страницы он сжимается на телефоне.
