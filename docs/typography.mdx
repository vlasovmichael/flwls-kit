# Типографика

Три гарнитуры: Geologica для заголовков, IBM Plex Sans для текста, IBM Plex Mono для чисел в колонках.

<ds-tokens kind="font"></ds-tokens>

## Шкала кегля

Шкала рассчитана на плотный интерфейс: основной текст 14 px, ячейка таблицы 13 px. Размер, которого нет
в шкале, в стилях не пишется.

<ds-tokens kind="text"></ds-tokens>

## Правила

- Числа в таблицах — `--mono` и `font-variant-numeric: tabular-nums`, чтобы разряды стояли друг под другом.
- Заголовок карточки — `--text-h2`, страницы — `--text-h1`. Между ними один шаг, не больше.
- Мельче `--text-label` — только служебные метки вроде LIVE.
