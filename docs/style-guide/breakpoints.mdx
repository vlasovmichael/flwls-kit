# Breakpoints

Layout breakpoints. CSS variables cannot be read inside `@media`, so these values are a reference for JavaScript and container queries; media queries repeat the numbers.

<ds-tokens kind="breakpoint"></ds-tokens>

## Rules

Design mobile first: tables switch to cards below `--breakpoint-md`.
