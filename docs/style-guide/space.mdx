# Space

Spacing scale on a 4 px grid. Small steps inside a component, large steps between cards and sections. A value that is not on the scale is not written in styles.

<ds-tokens kind="space"></ds-tokens>

## Rules

Distance inside a group is smaller than distance between groups — that is how the eye sees what belongs together. `--gap` is the only fluid token: it shrinks between sections on phones.
