# Colors

Click a token name to copy `var(--token)`. Values are read from the live theme — switch **Theme** in
the toolbar to compare light and dark.

## Primitives

Primitive colors are the building blocks of the color system. They are the same in every theme and are
**not used in product code** — semantic tokens below point to them.

## Semantic

Named by role, not by hue. These are the only colors product code uses.

## Choosing a color

- Text on a surface is `--ink`, `--ink-2` or `--ink-3`. Text has no other colors.
- Amounts, P&L and position side use `--gain` and `--loss`. A risk warning is `--caution`, never `--loss`.
- A status without money (saved, network error) uses `--data` and `--attn`.
- A background tint is always the `-wash` of the same color, never the base color with opacity.
