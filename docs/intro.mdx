# flwls-kit

Общая дизайн-система проектов: дашборд бота, health, guides. Один набор токенов и компонентов, чтобы
интерфейсы выглядели и вели себя одинаково, а правка цвета или отступа делалась в одном месте.

Переключатель **Тема** на панели сверху меняет тему у всех страниц и примеров: так видно, как токен
выглядит в светлой и тёмной теме.

## Принципы

- **Число важнее украшения.** Интерфейсы плотные: таблицы, графики, суммы. Цифры — моноширинным
  шрифтом, чтобы колонки не плясали.
- **Цвет — это смысл.** Зелёный — прибыль, красный — убыток, жёлтый — предупреждение. Цвет не
  используется для красоты, иначе он перестаёт что-то значить.
- **Одно действие на экране.** Акцентный цвет — у одной главной кнопки. Остальное нейтральное.
- **Токен вместо числа.** В стилях нет `13px` и `#2b5bd7`: только `var(--text-body)` и
  `var(--accent)`. Число, которого нет в шкале, — повод спросить, нужно ли оно.

## Подключение

Пакет ставится из GitHub по тегу — версия не меняется сама:

```bash
npm i -D "@flwls/ui@github:vlasovmichael/flwls-kit#ui-v0.3.0"
```

Токены — один CSS-файл во входе каждой страницы, до стилей проекта:

```js
import '@flwls/ui/tokens.css';
import './styles/app.scss';
```

Компоненты — веб-компоненты на Lit, работают в любом фреймворке:

```js
import '@flwls/ui';
```

```html
<h-stat label="Эквити" value="$105.09" note="за сутки +0.4%"></h-stat>
```

## Тема

Тёмная тема включается атрибутом `data-theme="dark"` на `<html>`, светлая — `data-theme="light"`.
Без атрибута тема следует настройке системы.

## Правило имён

Новые токены кита получают имена, которых нет ни в одном проекте. Одноимённый токен с другим значением
молча перебивает соседа — именно так уже ломалось. Проект, который вводит свой токен, называет его
с префиксом проекта.

## Выпуск

Исходники — `packages/ui` в ветке `main`. Выпуск: исходники вливаются в ветку `ui-release`, туда же —
собранный `dist`, и ставится тег `ui-vX.Y.Z`. Проекты обновляются по тегу сами, когда готовы.
