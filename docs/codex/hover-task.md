# Задача: состояния наведения у интерактивных компонентов

У `h-button` и `h-icon-button` (`packages/ui/src/h-button.ts`) нет `:hover` вообще, у
остальных интерактивных компонентов он еле заметен. Пользователь не видит, что можно нажать.

Сделать:
1. Пройти все интерактивные компоненты кита (кнопки, иконочные кнопки, select, segmented,
   tabs, pagination, dropdown-menu, disclosure/accordion, checkbox, radio, copy-button,
   date-picker, закрытие dialog/drawer/toast) и дать каждому явное состояние наведения:
   смена фона/рамки/цвета на токенах кита, плавный переход по токенам движения,
   без изменения размеров. Для каждого варианта (primary, secondary, ghost, danger и т.д.).
   Под `@media (hover: hover)`, чтобы на телефоне не залипало. `:active` — чуть сильнее.
2. Если нужных токенов (например, `--hover-wash`) нет — добавить в `tokens.css` для светлой и
   тёмной темы и задокументировать, как требуют тесты токенов.
3. Тесты на наличие hover-правил и сторис, где наведение видно (`pseudo-states` или явный класс).
4. `npm run verify` зелёный. Версию не менять (0.8.0 ещё не опубликован), тег не ставить.

Отчёт: `docs/codex/hover-report.md`. Коммиты Conventional Commits по-русски.
